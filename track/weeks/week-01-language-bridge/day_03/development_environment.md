# Development Environment — Week 01 Revision

## 1. What is a Development Environment?

A development environment is a collection of tools used to create and manage software projects.

## 2. Antigravity IDE

IDE stands for Integrated Development Environment.

It helps developers:
- Open project folders.
- Create files and folders.
- Write and run code.
- Find and correct errors.
- Use the terminal.
- Work with Git repositories.

## 3. MySQL

MySQL is a Database Management System (DBMS).

It is used to store and manage data, such as:
- Student details
- Login information
- Product details
- Orders
- Attendance and marks

## 4. MySQL Workbench

MySQL Workbench is a visual tool used to interact with MySQL.

Remember:
- MySQL manages the data.
- MySQL Workbench provides an interface to work with it.

## 5. Git and GitHub

### Git
Git is a version control system that tracks changes in project files.

### GitHub
GitHub is an online platform used to store, access and share Git repositories.

### Difference
- Git works locally on your computer.
- GitHub stores repositories online.

## 6. Repository

A repository is a project folder managed using Git.

Types:
- Local Repository: Exists on your computer.
- Remote Repository: Exists online, such as GitHub.

## 7. Important Git Commands

| Command | Purpose |
|---|---|
| git clone | Downloads a remote repository |
| git add . | Prepares changed files |
| git commit | Saves changes locally |
| git push | Uploads commits to GitHub |

## 8. Development Workflow

Clone → Understand → Build → Verify → Add → Commit → Push

## 9. Common Mistakes

- Working in the wrong project folder.
- Cloning the same repository repeatedly.
- Forgetting to save files.
- Uploading work without testing it.
- Using unclear commit messages.

## 10. What I Learned

I learned how to use development tools, manage project files, track changes with Git and store projects on GitHub.

# Programming vs Programming Language

## What is Programming?
Programming is the process of solving problems using logical instructions.

## What is a Programming Language?
A programming language is used to communicate instructions to a computer.

## What is Python?
Python is a programming language.

## Difference

- Programming focuses on logic and problem-solving.
- A programming language provides syntax to write instructions.
- The same logic can be implemented using Python, Java, or C++.

## Example

Programming Logic:
Check whether a candidate is eligible.

Python Code:
```python
percentage = 72
active_backlogs = 0

if percentage >= 60 and active_backlogs == 0:
    print("Eligible")
else:
    print("Not Eligible")

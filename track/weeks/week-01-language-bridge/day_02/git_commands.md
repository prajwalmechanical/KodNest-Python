# Git Commands — Week 01

## What is Git?
Git is a version control system used to track changes in project files.

## What is GitHub?
GitHub is an online platform used to store and share Git repositories.

## Git vs GitHub

- Git works on our local computer.
- GitHub stores repositories online.
- Git tracks project changes.
- GitHub helps us share projects.

## Important Git Commands

### 1. git clone
Downloads an existing remote repository to the computer.

Example:
git clone repository-url

### 2. git add .
Prepares all changed files for the next commit.

Example:
git add .

### 3. git commit
Saves prepared changes in the local repository.

Example:
git commit -m "Completed the assigned task"

### 4. git push
Uploads committed changes to the remote repository.

Example:
git push

## Basic Git Workflow

Clone → Understand → Build → Verify → Add → Commit → Push

## What I Learned

Git tracks project changes, while GitHub stores and shares repositories online.
